## Helper/representation and bounded-scope notes

- Rust production writer/reader pairs use `db::timestamps::{now_rfc3339,format_utc_timestamp,parse_db_timestamp,parse_row_timestamp}`; SQLite schemas and triggers emit the same fixed-millisecond UTC `Z` text via repeated literal `strftime('%Y-%m-%dT%H:%M:%fZ','now')`. The shared `SQLITE_UTC_NOW` constant exists in `db/timestamps.rs`, but production schema sources searched here embed the SQL literal instead of referencing the constant. Equal representation is source-evidenced; a single SQL helper owner is not.
- `config.db: checkpoints.created_ms` is an actual integer epoch-millisecond writer/reader pair, unlike the shared text contract. This inventory records the source shape and missing annual proof; it makes no contract decision about migration/normalization.
- The follow-up scope clarification treats WorkersDb, PlanDb, and GraphStore as direct P4 owners under TG4-19's every-database wording. Their source-grounded rows are now included above and below; this remains limited to the named direct owners and does not claim an exhaustive scan of every unrelated repository database.
- `worker_stats_monthly.covered_start/covered_end`, worker/date/month keys, session calendar fields, and other date buckets are civil dates/ranges rather than instants and are not timestamp fields in this matrix.
