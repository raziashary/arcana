# P4-53 one-use recovery admission — 2026-10-13

Approved boundary: ADR0380. Implement task/operation-bound retry permits in the existing append-only journal, with atomic single-use consumption and original snapshot revalidation under the replacement executor workspace lease. Preserve legacy holds and unknown outcomes. Use the existing authorization-UDF/RAII and additive migration patterns; no dependency.

A retry is explicit: write_file receives the original recovery_intent_cursor. A host grant is bound to the original task identity, owner, operation, path, content digest and overwrite intent. The replacement run must own a current atomic claim. Its admitted intent consumes the grant transactionally; a repeated cursor, different operation/args/owner/workspace or changed pre-state cannot run. Other effects without a verifiable contract remain held. Completion must not use an unconsumed grant or unknown replacement effect.
