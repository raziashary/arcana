## Numbered closure gaps

1. **Complete pair inventory — missing proof, not a confirmed defect.** P4-57 explicitly spans task, run, analytics, event, memory, and configuration databases. The current P4-57 evidence is selected-pair evidence; the audit says its compact inventory is not complete. Its named unpaired classes within these domains include task child-table timestamps/defaults/triggers (`arcana-core/src/db/tasks.rs`), run timestamp columns and the recent/open/latest-worker readers (`arcana-core/src/db/runs.rs`), AnalyticsDb monthly worker history (`arcana-core/src/analytics/db.rs::rollup_and_prune_worker_stats_before` → `get_worker_stats_range`), Memory table/default/trigger pairs (`arcana-core/src/memory`), and configuration/hooks pairs (`arcana-core/src/db/config_db.rs`, `arcana-core/src/hooks/db.rs`). Existing specific regressions for Memory, RunsDb, and Fleet Chat do not constitute this field-by-field inventory. Do not treat presence of schema defaults or parser tests as writer→reader evidence.

2. **Annual property/readback coverage at every pair — missing proof.** The explicitly annual production selections are `analytics_timestamp_pairs_...` in `arcana-core/src/analytics/db.rs`, `arcana-core/src/session/storage.rs`, and `arcana-core/src/hooks/db.rs`; the analytics report says monthly worker rollup→`get_worker_stats_range` is only one sample, not a full-year matrix. The current RunsDb chronology tests and Memory stats test exercise mixed legacy/canonical examples, not a year corpus. The Fleet Chat unit test is a three-row hydration case, not an annual producer/readback corpus. Thus, the present annual corpus cannot satisfy TG4-19's “at every write/read pair” wording.

3. **Three-host proof for the whole contract — missing evidence.** `.github/workflows/ci.yml` has a Windows/Linux/macOS `build-smoke` matrix and explicitly selects only the `analytics_timestamp_pairs_` Rust filter on each host. Hook evidence records Windows/Linux results and says no macOS result for the new writer; no cited record proves every P4-57 pair on all hosts. Rust's generic workspace test job is Ubuntu-only, and frontend unit tests are Ubuntu-only. The source workflow therefore supplies a macOS execution path for the selected annual tests, not proof that the complete contract passed there. No current remote CI result was queried in this read-only bounded review.

4. **Writer/helper convergence across all named databases — inventory proof missing; no new implementation defect established by this review.** The shared Rust helper and TypeScript legacy parser exist, and the inspected fixed consumers call the intended helpers. However, ADR-0128 notes schema SQL expressions are duplicated, and the partial inventory does not establish that every in-scope Rust writer/default/trigger emits the canonical fixed-millisecond UTC form or that every production reader uses the shared parser or instant-ordering equivalent. This clause needs the completed pair map from item 1, rather than a new behavior inferred from the duplicated SQL literals.
